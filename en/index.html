What a recommendation could look like

This example shows the format and controls. It contains no customer data or measured business results.

Example: website inquiry to CRM follow-up

  1. Validate the submitted fields and normalize the source record.
  2. Use a stable source ID to update an existing CRM lead instead of creating a duplicate.
  3. Summarize the inquiry against criteria supplied by the business; route unclear cases to a person.
  4. Create a follow-up draft for staff review. Do not send automatically.
  5. Log failures and retry safely; alert a person if the CRM remains unavailable.

Measures to establish before implementation: missing-field rate, duplicate rate, and time from inquiry to first human response. No improvement target is assumed without baseline data.
