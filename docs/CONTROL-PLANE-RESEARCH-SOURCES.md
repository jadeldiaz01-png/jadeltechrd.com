# Control-plane research source classes

Primary implementation research is taken from current first-party documentation: Cloudflare Developers for Workers/Turnstile/observability/Analytics Engine; Open Policy Agent documentation for deployment, bundles, decision logs and configuration; OpenBao documentation for audit/workload security; OpenTelemetry documentation for Collector gateway deployment; GitHub documentation for Actions and software-supply-chain controls.

Repository decisions remain evidence-driven and may be stricter than vendor defaults.
